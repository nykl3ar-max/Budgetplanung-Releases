# Budgetpools – Version 1.1

Einfache App zur Verwaltung des monatlichen Budgets.

## Neu in Version 1.1

* **Miete fest eintragen:** Mietstatus und Miethöhe direkt in der App hinterlegen.
* **Automatische Berechnung:** Hinterlegte Miete jeden Monat automatisch vom Gesamtbudget abziehen. Der Betrag bleibt bis zur nächsten manuellen Änderung gespeichert.
* **Screenshot-Schutz:** Neuer Schalter in den Einstellungen zum Erlauben oder Blockieren von Bildschirmfotos.

## Hauptfunktionen

* **Monatliches Budget:** Einnahmen und Ausgaben übersichtlich im Blick behalten.
* **Fixkosten-Abzug:** Feste monatliche Kosten wie die Miete direkt verrechnen.
* **Privatsphäre:** Finanzdaten bei Bedarf vor Screenshots schützen.

## Installation & Update

1. Aktuelle APK-Datei unter **Releases** (Version 1.1) herunterladen.
2. Datei auf dem Smartphone öffnen, um die App zu installieren oder zu aktualisieren.

Android 8.0 oder neuer wird benötigt.
